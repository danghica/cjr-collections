# Historical hash-map fragments

These three source fragments predate the current standalone hash_map.v development. They rely on imports and surrounding definitions from their original development and were not listed in the original monolith _CoqProject. They are retained byte-for-byte as archival text, rather than presented as standalone Rocq proof modules. The maintained hash-map definitions and proofs are in ../rocq/hash_map.v and are included in make verify.
