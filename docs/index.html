Getting started

Run make dependencies to check pinned sibling checkouts. Run make test, make benchmark, make docs, or make paper independently. These commands use the checked-in native sources and do not compile proofs. make build, make extract, make verify, and make readable explicitly invoke the Rocq toolchain.

Readable specifications

The renderer, launcher, packaging, resources, and tests live exclusively in cjr-core. This repository owns its documentation and cached outputs. Run make verify to revalidate proofs and make readable to regenerate specifications. Each report.json records rendering coverage and explanation availability.
